# 鸣法奇门·解断方法纲要

> 用途：把一张已排好的飞盘奇门盘（十大元素/宫）+ 用户的占问，交给本纲要所述的方法，逐步推理出「能否 / 方位 / 应期 / 理由」。
> 核心五步：①定用神 → ②查用神落宫及其十大元素 → ③以三乙四宫(天乙/太乙/地乙/时干宫)与年命宫的生克盗泄定成败 → ④以宫位定方位、以衍象定具体物象 → ⑤以用神下之地盘奇仪/暗干支定应期。

---

## 一、三乙四宫（断局之纲，最重要）

鸣法论吉凶，首重「三乙四宫」与「年命宫」的生克冲合。

| 名 | 取宫规则（从盘对象） | 主何事 |
|---|---|---|
| **天乙** | 天盘九神「值符(符)」所在宫 = 值符落宫(时干在地盘落宫) | 事情的**开始** |
| **太乙** | 人盘明值使门所在宫 = 明值使落宫 | 事情的**中间过程** |
| **地乙** | 地盘九神「值符(符)」所在宫 = 旬首宫(原宫) | 事情的**结局** |
| **时干宫** | 时干在**天盘奇仪**上所落之宫（甲时则取值符落宫） | 禀盘**主宰**，极重要 |
| **年命宫** | 求测人年命之天干在盘中所周游之宫（需用户提供年命） | 求测人自身 |

- 生克盗泄口诀：用神（或某宫）**生扶/比扶**年命宫 → 利、得；**克制**年命宫 → 阻、失；年命宫**克制**用神 → 多半亦可成（我能制之）；用神**脱泄**年命宫（泄气）→ 多凶、耗损。
- 逢**合**（天地盘干化合、暗支六合三合）：利于谋为、合作，不利病灾官讼（主纠缠不清）。逢**冲**：利于病灾官讼（逢冲必散），不利谋为。
- 旺衰：用神落宫得令为旺（有力），失令、入墓、空亡则力弱、事易落空。

## 三、应期 与 方位 / 数字

### 应期（"应期断在用神下"）
- **近期**：取**用神所在宫的地盘奇仪**定日。例：求财看生门宫，地盘是丙奇 → 应在**丙日**可得。
- **远期**：取**用神宫的地盘暗干支**定（年/月/日时）。
- **三乙定时空**：天乙=起始之时、太乙=过程之时、地乙=结局之时；逐宫之地盘干支推具体时点。
- 化合常主"纠缠/延后"，冲主"散/速决"。

### 方位（九宫定方所，含场所衍象）
| 宫 | 方位 | 场所/地形衍象 |
|---|---|---|
| 坎一 | 正北 | 沟渠、池塘、隐伏低洼之地、水边 |
| 坤二 | 西南 | 平原、郊野、学校、圈舍、田地 |
| 震三 | 正东 | 丛林、道路、运动喧闹场所 |
| 巽四 | 东南 | 文化场所、苗圃、花坛 |
| 中五 | 中央/室内 | 内室、庭院、窝穴、贴身之所、家 |
| 乾六 | 西北 | 高亢之所、神庙、高处 |
| 兑七 | 正西 | 沟渠、歌塔、喧哗言说之地、口形器物 |
| 艮八 | 东北 | 堤坝、山坡、城墙、山野、桌柜门径之下/旁 |
| 离九 | 正南 | 闹市、炉冶之所、明亮处、文书 |
- 内外盘：阳遁坎艮震巽为内(近)、离坤兑乾为外(远)；阴遁相反；中五恒为内。近处用内盘、远处用外盘。

### 河图数（定数字 / 远近层数）
| 干 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |
|---|---|---|---|---|---|---|---|---|---|---|
| 数 | 三 | 八 | 七 | 二 | 五 | 十 | 九 | 四 | 一 | 六 |
- 甲乙3·8东木、丙丁7·2南火、戊己5·10中土、庚辛9·4西金、壬癸1·6北水。
- 用时分阴阳、看旺衰，可取天地盘两干之和，或单取其一，贵在变通。

### 射覆 / 数字 / 天气（猜物·猜数·晴雨）
- **数字**（价格/分数/数量/号码）：取用神宫(或值符宫)天地盘干的河图数，旺相足数、休囚减半或取个位；可单取或两干相加；范围大则乘以宫数或层数。给出一个数或区间。
- **射覆猜物**：以用神宫**八卦类象**(坎水黑圆/坤土方布/震木动声/巽木长绳/乾金圆刚/兑金口缺/艮土止小/离火文丽) + 该宫九星门神奇仪之衍象，合参定物之形色质类。值符为主、值使为辅、用神宫为的。
- **天气**：雨看天蓬/壬癸落宫旺相(旺则雨大)，晴看天英/丙丁；辅星主风、柱星主阴、芮任主云雾。门宫和义晴、迫制变天。

## 五、解读流程（喂给 AI 的推理骨架）

1. **审题定类**：把占问归入第二节某一类，取出"用神"。
2. **定四宫一命**：算出天乙/太乙/地乙/时干宫、年命宫（用户提供年命则代入）各落何宫。
3. **看用神落宫**：读该宫十大元素（天盘星/神/仪/暗干支、明门/暗门/人盘暗干支、地盘神/仪/暗干支）+ 门宫格（和义/迫制）+ 遁干格 + 空亡/旺衰。
4. **断成败**：以用神宫、三乙四宫对年命宫的生克盗泄 + 合冲，定"能否/吉凶"。
5. **断方位物象**：用神（或玄武/对应神煞）落宫 → 方位+场所衍象；结合奇仪/门之物象，落到具体的人、物、地。
6. **断应期**：用神宫地盘奇仪定近期之日、地盘暗干支定远期；河图数定数字/层数。
7. **成文**：给出"能否、方位、应期、理由(引用上述元素与格局)"。

> 例（失物·寻钥匙）：用神=伤门(+年命)。伤门落宫定能否(伤门生/比年命→可寻回)；玄武或伤门落宫定方位(如坎一=正北)；该宫地盘衍象(如艮八桌柜之下、坎一低洼水边)定具体处；地盘奇仪定何日寻见。
