# 山向奇门·宅盘解断方法纲要

> 用途：把一张已排好的**宅盘**（坐山定局所排九宫）+ 坐山向首 + 用户所问，
> 按本纲要推出「宅之吉凶 / 何方旺何方煞 / 何处宜何用 / 如何调整」。
> **与时家不同**：时家断一时一事之成败；宅盘断一宅长久之气场格局，落点在**方位与空间**，
> 结论须能直接落到户型图上。九宫方位与罗盘一致（离九正南、坎一正北、震三正东、兑七正西）。

---

## 一、断宅总纲（向首为用，坐山为体）

| 位 | 取宫 | 主何事 |
|---|---|---|
| **向首宫** | 向首所在之宫 | **纳气之口**——门面、财路、外缘、对外运势。宅之"用" |
| **坐山宫** | 坐山所在之宫 | **根基**——人丁、健康、家运根本、主人身心。宅之"体" |
| **中五宫** | 中宫 | **宅心**——全家总气、核心事务；中宫受克则举家不安 |
| **值使门宫** | 值使所落之宫 | **动线与门户**——实际出入、活动之所向 |
| **值符宫** | 值符所落之宫 | **贵人位/主事位**——宜静宜尊，忌污秽 |

**断法次第**：
1. 先看**向首宫**：吉门吉神旺相 → 纳气佳、财路通、外缘好；凶门受迫、空亡入墓 → 门庭不利、来财受阻。
2. 再看**坐山宫**：旺相有力 → 根基稳、人丁健旺；休囚死或四害 → 根基虚、主人易疲病。
3. 合看**体用生克**：向首宫**生**坐山宫 → 外财养家、进气归身（大吉）；坐山宫生向首宫 → 家资外泄、劳而少得；向首宫**克**坐山宫 → 外邪冲宅、压力自外来；坐山宫克向首宫 → 主人能制外局，虽费力而可掌控；**比和** → 内外相安。
4. 再逐宫定各方吉凶（第三节），落到房间用途与调整建议。

> **旺衰与四害必用**：宅盘同样须查【旺衰与四害】块——旺相之吉方才真旺；吉门若逢门迫/击刑/空亡/入墓，其吉大打折扣，不可空言"此方大吉"。（口诀与减力见时家纲要「旺衰与四害」节，同法适用。）

## 二、九宫的宅象（方位 · 家人 · 场所）

| 宫 | 方位 | 家人（八宅六亲） | 宅中常对应之处 |
|---|---|---|---|
| 坎一 | 正北 | 中男 | 卫浴、水管、低洼、后门、隐秘处 |
| 坤二 | 西南 | 母 / 女主人 | 厨房、储藏、腹地、老母居所 |
| 震三 | 正东 | 长男 | 大门通道、车库、声响处、电器 |
| 巽四 | 东南 | 长女 | 书房、文昌、风口、绳索管线 |
| 中五 | 宅心 | 全家 | 中庭、客厅核心、楼梯井 |
| 乾六 | 西北 | 父 / 男主人 | 主卧、神位、书房、高处、男主人位 |
| 兑七 | 正西 | 少女 | 口舌处、娱乐、餐厅、水池 |
| 艮八 | 东北 | 少男 | 门径、玄关、库房、山墙、桌柜之下 |
| 离九 | 正南 | 中女 | 明堂、客厅、炉灶电器、文书 |

- 某宫见**凶门凶神又逢四害** → 该方位所属**家人**易应其事（如乾六大凶主男主人不利、坤二凶主女主人或脾胃）。
- 某宫为**吉门旺相** → 该方位可作重要用途（主卧/书房/办公/财位）。

## 三、八门在宅盘的场所义（定各方宜忌）

| 门 | 宜（旺相时） | 忌（受迫/休囚时） |
|---|---|---|
| **开门**(金·吉) | 大门、玄关、办公、迎客——通达官贵 | 受迫则门庭不畅、事业阻 |
| **生门**(土·吉) | **财位**、收银、厨房、主卧——生发进财 | 空亡入墓则财源虚而不实 |
| **休门**(水·吉) | 卧室、休憩、会客——安养得贵人 | 逢凶则慵懒、精神不振 |
| **景门**(火·吉平) | 书房、文昌、窗景、宣传 | 过旺主血光、口舌文书之争 |
| **杜门**(木·凶) | 储藏、保险柜、隐私、技术房 | 作主卧则阻塞压抑、消息不通 |
| **伤门**(木·凶) | 健身、机械、竞技（借其动象） | 忌大门/主卧——主伤损、路冲、车关 |
| **死门**(土·凶) | **厕所、储物、杂间**（以凶制凶） | 忌大门/厨房/主卧——主停滞病丧 |
| **惊门**(金·凶) | 律法、口才、演艺（借其声象） | 忌卧室——主惊恐口舌官非 |

**布局要诀**：**吉门之方安重要用途，凶门之方安厕所储物**——此即"以凶制凶、趋吉避凶"之正法。

## 四、八宅游年参照（东西四宅，辅证之用）

宅卦以**坐山**定（坐北为坎宅、坐南为离宅、坐东为震宅、坐东南为巽宅、坐西北为乾宅、坐西南为坤宅、坐东北为艮宅、坐西为兑宅）。

- **东四宅**：坎、离、震、巽；**西四宅**：乾、坤、艮、兑。东四命宜住东四宅，西四命宜住西四宅。
- **四吉方**：生气（旺财，宜书房/主卧/财位）、延年（旺感情，宜夫妻卧）、天医（利健康，宜老人/病者静养）、伏位（平稳，宜储物/次卧）。
- **四凶方**：绝命（最凶，宜厕所储物）、五鬼（火灾口舌，忌厨房电器集中）、六煞（烂桃花，忌卧室）、祸害（小人破财，忌财位书房）。

> 用法：八宅为**辅证**——以奇门宅盘九宫吉凶为主，八宅吉凶方相合者，其断更确；相悖者，以奇门盘为准并说明分歧。

## 五、形势峦头与常见形煞（峦头为体，理气为用）

> 《葬书》重"藏风聚气"：背有靠、前有明堂、左右有护。**峦头差则理气无用**——若用户描述了外部环境，须先以形势论，再以盘断。

| 煞 | 形态 | 处理（移形易位优先，摆件次之） |
|---|---|---|
| 路冲煞 | 道路直冲大门 | 玄关/屏风阻隔；石敢当、凸镜 |
| 天斩煞 | 两楼夹缝正对窗 | 遮挡、厚窗帘；忌该位久坐 |
| 壁刀煞 | 邻楼墙角切向本宅 | 凸镜、绿植遮挡 |
| 反弓煞 | 弯道弓背对宅 | 高墙/绿篱遮挡；严重者宜迁 |
| 穿堂风 | 大门正对后门或窗 | 设玄关屏风，留住气 |
| 横梁压顶 | 梁压床头/座位 | 移位；不得已做假天花 |
| 镜对床 | 镜正对睡床 | 移开或夜间遮盖 |
| 厕居中宫 | 厕所在宅心 | 常通风保洁、少用；宜改格局 |

**化解原则**：**能改格局者优先改格局**（移床、改门向、调用途），器物次之。不推荐"必须摆某物才能化解"之说。

## 六、解读流程（喂给 AI 的推理骨架）

1. **读宅基**：坐山、向首、所定之局；标明这是宅盘而非时家一事之盘。
2. **称量力量**：查【旺衰与四害】块，得向首宫、坐山宫、中五、值符值使宫之实际力量。
3. **断体用**：向首宫 ↔ 坐山宫之生克（第一节第 3 条）→ 定全宅总格局吉凶。
4. **逐宫断方**：九宫逐一断吉凶，结合第二节家人/场所与第三节八门宜忌 → **何方旺、何方煞、何方宜作何用**。
5. **辅以八宅**：以坐山定宅卦，取四吉四凶方，与奇门盘互参（第四节）。
6. **合形势**：若用户述及外部环境，按第五节论形煞与化解。
7. **成文**：① 总断一句（此宅格局吉凶）② 向首/坐山/宅心详析 ③ 各方位吉凶与宜忌（可落户型图）④ 具体调整建议（移位/改用途/择方）⑤ 需留意之处。

## 七、诚实边界（须遵守）

- **风水为辅、人为为主**。《宅经》云「地善则苗茂，宅吉则人荣」——宅提供有利条件，非决定命运之术。断语不作绝对化承诺。
- 未见户型图/未实地勘察者，须注明「以所述为准，如有偏差请补充」；外部峦头远程只能作初步判断。
- 不恐吓、不夸大：凶象未至明显发作程度者，说明隐患即可。
- 不引入本纲要之外的伪术（水晶阵、转运符之类），不属传统堪舆者直言其非。
- 山向奇门起局法流派不一，本盘依「坐山→节气→三元定局」所排；如用户所宗流派不同，应说明此点而非强断。
