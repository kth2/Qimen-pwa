# 转盘奇门·解断方法纲要

> 用途：把一张已排好的转盘奇门盘 + 引擎已算出的解断(用神宫/格局/九宫吉凶/建议) + 用户占问，交由本纲要所述方法，逐步推理出「能否 / 方位 / 应期 / 理由」。
> 与飞盘不同：转盘已有确定性解断引擎，本纲要主要补充①用神取用②应期法③方位衍象，AI 应**优先采信引擎算出的吉凶与格局**，再据占问聚焦作答。

---

## 一、断局总纲（值符值使为纲，用神年命为目）

- **值符**=值班九星(贵人/事体主导)，**值使**=值班八门(行动/落点)。引擎已给出二者落宫吉凶，先看此二宫定大势。
- **日干为人、时干为事**（断局第一层，诸占通用）：**日干**天盘落宫=求测人自身（未提供年命时，以日干宫代年命宫）；**时干**天盘落宫=所占之事/对方。先审两宫生克定成败大局：
  - 时干宫**生**日干宫 → 事来就我、易成；**比和** → 顺遂可成；
  - 日干宫**克**时干宫 → 我能制事、谋为可成（但费些气力）；
  - 时干宫**克**日干宫 → 事制我、受阻多败；
  - 日干宫**生**时干宫 → 我劳而耗、泄气费力难成。
  - 兼看两宫旺衰、空亡、门迫：时干宫空亡主事虚悬待填实；日干宫空亡主自身心神不定。
  - 甲干不上天盘（遁于旬首）：日/时干为甲时，以值符落宫论之。
- 时干宫为**诸占通用之辅助用神（事体）**，与第二节的专用神互参：专用神断事之性质吉凶，时干宫断事之向背成败。
- **用神**=所占之事的代表符号(见第二节)，落宫之吉凶、与年命宫(求测人)的**生克盗泄**定成败：
  - 用神宫**生扶/比扶**年命 → 得、利；用神宫**克**年命 → 我受制、阻；
  - 年命**克**用神 → 我能制之、多可成；用神宫**脱泄**年命(我生用神) → 耗损、多不成。
- **门宫格**：门生宫/比宫=和义(吉)；门克宫=门迫(凶，吉门减力凶门更凶)；宫克门=门受制。
- **十干克应**(天盘干+地盘干，81格)：引擎已识别格名吉凶(如戊+丙青龙返首吉、庚+戊值符飞宫凶)，直接采信。
- **空亡**：吉凶力减半、事易落空、宜实不宜虚，需待"填实/冲实"之时方应。
- **逢合**(干合/支合)主纠缠、延后、合作；**逢冲**主散、速决、动。

## 二、用神取用（按占问类型；引擎亦已按目的算出用神宫）

| 占问 | 用神（主 + 辅） | 要点 |

| 求财 / 财运 | 生门 + 戊(财星) | 生门、戊落宫旺相、逢生为得；空亡入墓、被克为损 |
| 事业 / 求职 | 开门 + 值符 | 开门旺、值符吉、与年命相生则升迁顺遂 |

| 疾病 / 健康 | 天芮(病符) + 天心(医) + 生死门 | 芮旺病重；天心、生门旺、克芮为愈；死门、芮临年命凶 |

| 出行 / 远行 | 开门 + 驿马 | 开门吉、马星动利行；伤杜门、马空则阻 |

| 风水(阴阳宅) | 阳宅:中五/值使/生门；阴宅:死门/九地 + 年命 | 阳宅看中宫与值使、生门旺相；阴宅看死门/九地/坟茔；以与年命生克定旺衰 |

| 行人来否 | 用神(所代之人) + 驿马 | 用神临马星、生年命、门吉→必来；入墓空亡→未动/不来 |
| 竞赛 / 比赛胜负 | 值符(我方) + 时干宫(对方/客) + 天冲(竞技) | 主客法：值符宫旺相并克制时干宫→我方胜；被克/脱泄→负；比和→平局或延期。竞标同法，天盘为客(挑战方)地盘为主(应战方) |
| 谋望 / 综合 | 值符值使 + 年命 + 时干 | 综合看全盘旺衰生克，引擎建议为主 |

> 衍象类象：人/物/事各取对应符号(见第四节)，落宫定方位、临神临门定性质。

## 三、应期 与 方位 / 数字（转盘通行法）

### 应期（取"动而填实"之时）
依左耶老道案例，转盘应期常用以下几法，择最显者：
1. **用神宫干支定日**：用神所落宫的天盘干 / 地盘干 → 对应之日辰(如用神坐丙→丙日)。
2. **空亡填实/冲实**：用神或关键宫空亡 → 应在"填实之日"(该地支当值之日)或"冲实之日"(冲动空支之日)。
3. **马星(驿马)发动**：盘中见驿马 → 应在寅申巳亥(马星)之日/月；伏吟主静，静中以马星为动机。
4. **墓库出墓/冲墓**：用神入墓 → 应在出墓或冲墓之日。
5. **远近**：近事看日时、中事看月、远事看年；得令旺相则应速，休囚墓绝则应迟。

|---|---|---|
| 坎一 | 正北 | 沟渠池塘、水边、隐伏低洼、卫浴 |
| 坤二 | 西南 | 平原田野、村庄、腹/库房 |
| 震三 | 正东 | 大途道路、丛林、闹市、车马 |
| 巽四 | 东南 | 花草林木、文教、风口、绳索 |
| 中五 | 中央/室内 | 中堂、内室、贴身、核心之处 |
| 乾六 | 西北 | 高亢、楼台、神庙、官府、首脑 |
| 兑七 | 正西 | 池泽、沟渠、口形器物、娱乐喧哗 |
| 艮八 | 东北 | 山坡丘陵、堤坝、门径、桌柜之下/旁、坟 |

### 射覆 / 数字 / 天气（猜物·猜数·晴雨）
- **数字**（价格/分数/数量/号码）：取用神宫(或值符宫)天地盘干的河图数，旺相足数、休囚减半或取个位；可单取或两干相加；范围大则乘宫数/层数。给出一个数或区间。
- **射覆猜物**：以用神宫**八卦类象**(坎水黑圆/坤土方布众/震木动声/巽木长绳风/乾金圆刚贵/兑金口缺泽/艮土止小山/离火文丽中虚) + 该宫九星八门八神十干之衍象，合参定物之形色质类。值符为体、值使为用、用神宫为的。
- **天气**：雨看天蓬/壬癸落宫旺相(旺则雨大)，晴看天英/丙丁；天辅主风、天柱主阴、天芮天任主云雾。门宫和义主晴、迫制主变天。

## 四、衍象速查（解读每宫"物象"，与引擎常量一致）

### 九星（事体性质 / 人物）
天蓬(水)：盗贼/机变/口才；天芮(土)：病符/迟钝/医药；天冲(木)：冲动/军警/快速；天辅(木)：文教/扶助/斯文；天禽(土)：枢纽/中正/贵；天心(金)：医药/决断/领导；天柱(金)：口舌/破耗/坚固；天任(土)：稳实/田产/责任；天英(火)：才华/虚荣/血光。

### 八神（情态 / 助力）
值符(吉)：贵人福庆；腾蛇(凶)：虚惊怪异；太阴(吉)：暗助谋密；六合(吉)：和合婚介；白虎(凶)：凶伤道路争斗；玄武(凶)：盗贼欺诈暗昧；九地(吉)：稳固藏纳；九天(吉)：高远扬名。

### 十干（天地盘干，性情/物象）
甲(栋梁/首领)、乙(花木/妻/柔)、丙(权威/光明/火)、丁(文书/星火/女)、戊(财货/墙宅)、己(田土/暗昧/陷)、庚(刀兵/仇敌/道路)、辛(金刃/错误/首饰)、壬(江河/流动/牢)、癸(雨露/规矩/暗)。

### 八十一干加干格局（十干克应）
引擎已按天地盘干识别**格名与吉凶并随盘附上，直接采信**。常用速查（天盘干加地盘干）：

| 类 | 常见格 | 吉凶与义 |
|---|---|---|
| 青龙类 | 戊+丙青龙返首、丙+戊飞鸟跌穴 | 大吉，谋事称心、贵人助、事半功倍 |
| 白虎类 | 庚+辛白虎猖狂、辛+庚白虎干格 | 大凶，家破人亡、道路损伤、争斗刑伤 |
| 朱雀类 | 壬+丁朱雀投江、丁+壬雀入江 | 凶，文书口舌是非、信息有诈 |
| 螣蛇类 | 癸+丁螣蛇夭矫、丁+癸雀投罗网 | 凶，虚惊怪异、事多反复牵缠 |
| 太白类 | 庚+丙太白入荧、丙+庚荧入太白 | 凶，客胜主(庚丙)或主破客(丙庚)，破财失盗、争端 |
| 伏吟类 | 乙+乙日奇伏吟、庚+庚太白同宫 | 平至凶，事主静滞不动、久拖难成；庚庚为战格主争 |

| 入墓/刑格 | 见下「四害」节 | 力弱、滞塞、别扭拧劲 |

## 四之二、旺衰与奇门四害（**断强弱成败的关键，必用**）

> 盘上另附【旺衰与四害】块（由 `core/wangshuai.js` 补算）。**此为断"能不能成"的力量依据，不可略过。**

### 旺相休囚死（以月令定四时）

| 当令 | 旺 | 相 | 休 | 囚 | 死 |
|---|---|---|---|---|---|
| 春(寅卯·木) | 木 | 火 | 水 | 金 | 土 |
| 夏(巳午·火) | 火 | 土 | 木 | 水 | 金 |
| 秋(申酉·金) | 金 | 水 | 土 | 火 | 木 |
| 冬(亥子·水) | 水 | 木 | 金 | 土 | 火 |
| 四季(辰未戌丑·土) | 土 | 金 | 火 | 木 | 水 |

口诀：**当令者旺、令生者相、生令者休、克令者囚、令克者死。**
- 用神/值符/值使/日干/时干宫**旺相**→事有力、可成、应速；**休囚死**→力弱、难成、应迟。
- 旺相之凶格，凶亦有力（凶得更凶）；休囚之吉格，吉亦无力（吉而不显）。**不可只看吉凶不看旺衰。**

### 奇门四害（门迫 / 击刑 / 空亡 / 入墓）

| 害 | 判法 | 减力与断义 |
|---|---|---|
| **门迫** | 门克宫（引擎已判） | 减半。吉门受迫则吉不成，凶门受迫则凶更烈 |
| **击刑** | 六仪落其刑宫：戊→震三、己→坤二、庚→艮八、辛→离九、壬→巽四、癸→巽四 | 减半。主别扭拧劲、事不顺遂、彼此掣肘 |
| **空亡** | 旬空之宫 | 吉凶皆减半；**事悬而未决，须待「填实」(该支值日)或「冲实」(冲动空支)之时方应** |
| **入墓** | 十干落墓宫：**乙丙戊→乾六、甲癸→坤二、丁庚己→艮八、壬辛→巽四** | 仅余约两成。能量深藏难发，主滞塞、困顿、事被压住 |

**要诀：**
1. 同宫多害则**减力相乘**（如既入墓又击刑者，几近无力）。断语须明写"因×害故力弱"，不可无视四害空言旺相。
2. **旺相而入墓**者：本有力而暂被困，应期多在**冲墓**之年月日时（冲开墓库则发）。
3. **衰死又入墓**者：谋事难遂，**不可强断为吉**，宜劝待时或改图。
4. 用神空亡：所问之事多虚、或对方无心、或时机未到；须断"何时填实/冲实"作应期。

## 五、解读流程（喂给 AI 的推理骨架）

1. **审题定用神**：占问归类→取用神(第二节)；引擎已附"用神宫"可直接用。
2. **采信引擎解断**：先读盘上附带的 值符/值使宫吉凶、格局(geju)、九宫详解(jiuGongAnalysis)、综合建议(analysis)。
3. **聚焦用神宫**：读其星/门/神/天盘干/地盘干/暗干+门宫格+十干克应+空亡旺衰。
3.5. **称量力量（必做）**：查【旺衰与四害】块——用神宫、值符值使宫、日干宫、时干宫各自旺相休囚死与四害，得其**实际力量**。吉凶定方向，旺衰定成败大小与迟速；二者须合参，缺一不可。
5. **断方位物象**：用神(或玄武等)落宫→方位+场所；结合衍象落到具体人/物/地。
6. **断应期**：用神宫干支定日 / 空亡填实冲实 / 马星动 / 出墓(第三节)。
7. **成文**：① 结论一句话 ② 方位 ③ 应期 ④ 详细理由(逐条引用盘面元素与格局)。

> 例（失物·寻钥匙）：用神=玄武(盗向)+伤门/年命。玄武或用神落宫定方位(如坎一正北水边、艮八桌柜之下)；该宫衍象定具体处；用神宫地盘干定何日寻见；引擎若判此宫为凶/空亡，则示难寻或迟得。
